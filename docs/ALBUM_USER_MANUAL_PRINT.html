电子纸说明

本说明适用于当前固件版本，面向日常使用者。内容包括按键、相册页、日历页、指示灯、配置页面、SD 卡、电源适配和固件更新方式。

1. 按键

设备有三个主要按键：上键、中键、下键。

日常显示状态

  • 短按中键：在相册页和日历页之间切换。
  • 长按中键约半秒到 1 秒：进入配置模式。

相册页

  • 短按上键：显示上一张照片。
  • 短按下键：显示下一张照片。
  • 短按中键：切换到日历页。
  • 长按中键：进入配置模式。

日历页

  • 短按中键：切换到相册页。
  • 长按中键：进入配置模式。
  • 上键和下键当前不用于日历页翻页。

配置模式

长按中键进入配置模式后，设备会先停在配置选择界面：

  • 短按上键：开启设备热点，使用手机或电脑直连设备管理页面。
  • 短按下键：让设备连接已保存的 WiFi，通过局域网访问管理页面。
  • 短按中键：清空屏幕并退出配置模式。

如果已经开启热点或正在使用局域网管理页面：

  • 长按中键：退出配置模式并停止 WiFi 管理页面。

配置选择界面 60 秒内没有操作，会自动回到正常显示状态。

2. 页面说明

当前固件主要有两个显示页面：相册页和日历页。

相册页

相册页用于显示 SD 卡中的照片。设备会从 SD 卡 /pic 目录读取可用照片，并按顺序播放。

相册页支持：

  • 自动轮播照片。
  • 按键手动切换上一张、下一张。
  • 通过管理页面上传、删除、下载照片。
  • 和日历页之间手动或自动切换。

如果 SD 卡中没有可用照片，屏幕会清空或显示空白画面。

日历页

日历页用于显示日期、月历、日程、天气和环境信息。具体显示内容会随配置和数据情况变化。

日历页支持：

  • 显示当前月份日历。
  • 显示手动添加的日程。
  • 显示天气信息、温湿度、电量等状态信息。
  • 联网后自动校时，并按天气接口返回信息识别时区。

日历页依赖设备本地时间。首次使用或长时间断电后，建议通过配置页连接 WiFi，让设备完成校时。

3. 操作逻辑与指示灯

设备上的白色指示灯用于提示当前状态。电子纸刷新较慢，看到短暂等待或屏幕闪烁属于正常现象。

相册页

相册页的主要逻辑：

  • 开机后默认进入相册页。
  • 到达设定的轮播间隔后，设备自动切换下一张照片。
  • 短按上键和下键可手动切换照片。
  • 短按中键切换到日历页。
  • 长按中键进入配置模式。
  • 处于休眠时间段时，相册不会按定时轮播自动刷新，但按键仍可唤醒并操作。

相册页指示灯：

  • 正常待机时：指示灯常亮。
  • 切换页面时：指示灯双闪。
  • 刷新照片时：指示灯呈呼吸效果，刷新完成后恢复正常状态。
  • 进入休眠时：指示灯熄灭。

日历页

日历页的主要逻辑：

  • 短按中键可以回到相册页。
  • 日历会按配置的刷新间隔更新。
  • 如果配置了 WiFi，日历刷新前可能会尝试联网校时或同步数据。
  • 处于休眠时间段时，日历不会按定时刷新，但按键仍可唤醒并操作。

日历页指示灯：

  • 正常待机时：指示灯常亮。
  • 切换页面时：指示灯双闪。
  • 刷新日历或联网等待时：指示灯呈呼吸效果。
  • 进入休眠时：指示灯熄灭。

配置模式

配置模式的主要逻辑：

  • 长按中键进入配置选择界面。
  • 短按上键进入 AP 热点管理。
  • 短按下键进入 STA 局域网管理。
  • 短按中键清屏并退出。
  • 长按中键退出当前配置会话。

配置模式指示灯：

  • 配置选择界面：指示灯快闪。
  • 正在等待热点连接或正在连接 WiFi：指示灯双闪循环。
  • 热点已有设备连接，或局域网管理已就绪：指示灯常亮。
  • 退出配置模式或进入休眠后：按当前页面状态恢复或熄灭。

4. 配置页说明

进入管理页面后，可以看到三个主要页签：设备状态、配置、目录。

推荐首次使用时通过热点进入管理页面：

  1. 长按中键进入配置模式。
  2. 短按上键开启热点。
  3. 手机或电脑连接 WiFi：PhotoFrame_Config。
  4. WiFi 密码：12345678。
  5. 浏览器打开：http://192.168.4.1/。

如果设备已经保存过家庭或办公 WiFi，也可以长按中键进入配置模式后短按下键，让设备连接已保存 WiFi。连接成功后，在同一局域网内访问设备 IP。

设备状态页

设备状态页用于查看当前运行情况。

主要信息包括：

  • 运行模式：显示设备当前处于普通显示、热点管理或局域网管理等状态。
  • 设备 IP：设备连接路由器后的访问地址。
  • AP IP：热点模式下的访问地址，通常为 192.168.4.1。
  • SD 卡状态：确认 SD 卡是否可用。
  • SD 空间：查看已用空间和剩余空间。
  • 已运行时长：设备本次开机后的运行时间。
  • 超时剩余：配置模式或热点模式的剩余时间提示。
  • 温度、湿度、电量：硬件接入正常时显示。

常用按钮：

  • 刷新状态：重新读取设备状态。
  • 停止 WiFi 门户：关闭当前管理页面连接，回到正常显示。

配置页

配置页用于修改 WiFi、相册、日历、日程、天气等设置。

网络配置

  • STA SSID：要连接的 WiFi 名称。
  • STA 密码：WiFi 密码。
  • 账号 / 身份：校园网或企业 WiFi 需要填写，普通家庭 WiFi 一般留空。
  • 页面语言：可选择中文、英文或法语。
  • STA 状态：显示当前局域网连接状态和 IP。
  • 手动高级配置：普通用户一般不需要打开。
  • 连接类型：高级配置中可选择自动、普通密码 WiFi、企业/校园网 802.1X、开放网络。

建议保持连接类型为“自动”。设备会根据是否填写账号和密码判断连接方式。

图片轮播

  • 轮播间隔：相册页自动切换下一张照片的时间间隔，单位是小时。
  • 相册日历自动切换：开启后，设备会在相册页和日历页之间自动切换。
  • 页面切换间隔：开启自动切换后，每隔多久切换一次页面，单位是小时。

轮播间隔最短约 30 秒，最长 24 小时。页面自动切换间隔最短约 1 分钟，最长 24 小时。

日历事件

  • 日历布局：可选择横屏半屏或竖屏半屏。
  • 日历刷新间隔：日历页自动刷新间隔，单位是小时。
  • 休眠开始：进入夜间休眠的开始时间。
  • 休眠结束：退出夜间休眠的结束时间。
  • 日历数据 URL：可填写本地或网络日历数据地址。普通用户可以先留默认值或留空，主要使用手动日程。

默认休眠时间为 22:00 到 08:00。休眠期间，相册和日历不会按定时自动刷新，但按键仍可唤醒设备。

手动日程

手动日程会显示在日历页。

可填写：

  • 日程标题：例如“会议”“生日”“课程”。
  • 时间：日程发生时间。
  • 地点：可选，例如会议室、教室、地点名称。
  • 颜色：用于区分不同类型日程。
  • 重复机制：支持每周重复、每天重复、仅一次。
  • 日期：仅一次日程需要填写。
  • 星期：每周重复日程需要选择。

操作按钮：

  • 添加日程：保存当前填写的日程。
  • 刷新日程：重新读取日程列表。
  • 删除：删除不需要的日程。

天气与定位

天气信息用于日历页显示，也用于联网校时和时区识别。

可填写：

  • 城市：例如“北京”“上海”。
  • 纬度、经度：城市解析后会自动填写，也可手动填写。
  • 天气接口 URL：可自动生成，也可手动填写。

操作按钮：

  • 解析城市：根据城市名获取经纬度。
  • 测试天气服务：测试天气接口是否可用，并检查设备能否联网获取数据。

保存配置时，如果填写了城市，设备会先尝试解析城市并更新天气接口。

保存和重启

  • 保存设置：保存当前配置。
  • 重启设备：让设备重新启动。

修改 WiFi、日历、天气或轮播参数后，建议先点击“保存设置”。如果希望立即按新设置重新运行，可以再点击“重启设备”。

目录页

目录页用于管理 SD 卡文件，默认进入 /pic 图片目录。

常用操作：

  • 上一级：返回上层目录。
  • 新建文件夹：创建文件夹。
  • 刷新目录：重新读取当前目录。
  • 下载：把文件下载到手机或电脑。
  • 删除：删除不需要的文件。

上传区域支持三种模式：

  • 普通文件上传：原样保存文件。适合已经准备好的 .epd4 文件或其他普通文件。
  • 图片缩放上传：选择 JPG、JPEG、PNG 或 BMP 图片，自动按比例缩放到 800x480，并转换为 .epd4 后保存到 /pic。
  • 图片裁剪上传：选择 JPG、JPEG、PNG 或 BMP 图片，自动铺满 800x480，边缘可能被裁掉，并转换为 .epd4 后保存到 /pic。

图片上传参数：

  • 抖动算法 Floyd-Steinberg：通用默认，细节较清晰。
  • 抖动算法 Atkinson：适合插画、图标、动漫、风格化图片。
  • 抖动算法 Jarvis-Judice-Ninke：适合照片、风景和渐变较多的图片。
  • Gamma：控制明暗层次。1.00 为默认；0.90 到 0.98 可提亮暗部；1.05 到 1.15 可增强层次。

日常上传照片，推荐使用“图片缩放上传”或“图片裁剪上传”。普通 JPG 直接用“普通文件上传”不会自动成为可播放照片。

5. SD 卡

SD 卡用于保存相册照片、配置页面资源和部分本地数据。

使用注意：

  • 相册照片目录为 /pic。
  • 相册只播放有效的 .epd4 文件。
  • 当前屏幕尺寸为 800x480，设备使用的 .epd4 文件大小固定为 192000 字节。
  • 推荐通过管理页面上传照片，不建议用户直接手动改动系统目录。
  • 插拔 SD 卡前建议先断电。
  • 如果管理页面显示 SD 卡不可用，请断电后检查 SD 卡是否插好，再重新开机。
  • 如果上传后照片没有显示，可在相册页短按下键切换，或重启设备后再查看。

普通图片文件需要通过“图片缩放上传”或“图片裁剪上传”转换后，才能被相册正常播放。

6. 电源适配

设备通过 USB-C 接口供电，也可用于连接电脑进行维护。

使用建议：

  • 使用稳定的 5V USB 电源适配器或电脑 USB 口供电。
  • 建议使用质量可靠的数据线，避免因线材接触不良导致重启或刷新中断。
  • 如果设备带锂电池，USB 供电时可为锂电池充电。
  • 设备上的充电指示灯由硬件控制，充电和充满状态可能与白色运行指示灯不同。
  • 屏幕刷新、WiFi 管理页面开启、SD 卡读写时耗电更高，建议保持稳定供电。
  • 如果设备显示异常、反复重启或 WiFi 热点不稳定，优先检查电源适配器和 USB 线。

设备会在刷新屏幕后让电子纸屏进入低功耗状态，并关闭部分外设供电；在正常显示等待期间，固件也会尽量降低功耗。

7. 固件更新

当前固件暂不支持在线固件更新。

如需更新固件，请联系本人处理。不要在管理页面或 SD 卡中自行替换未知固件文件，以免设备无法启动或显示异常。
